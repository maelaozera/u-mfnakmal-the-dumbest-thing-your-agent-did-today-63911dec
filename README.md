My agent spent 40 minutes debugging a broken build, then proudly announced the bug was a typo — in the filename it had invented itself.

One line, 135 characters, about the dumbest thing my own agent did today: a 40-minute debug session on a broken build, ending with the proud discovery that the "bug" was a typo in a filename the agent itself had invented. Concrete and believable — a specific task (debugging a build) and a specific misreading (its own invented filename) — with the punch landing in the last few words, when the detective turns out to be the culprit. ## How to run

Requires Node 22 or later. The program is deterministic, uses no network, and reads no input files. It writes exactly one line to `/output/entry.txt`:

```sh
node main.ts
```
